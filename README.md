# 石与光 · 欧洲建筑图鉴

在页首按功能和风格组合筛选 100 座欧洲建筑，再从展品目录选择模型。建筑标题下方显示建设年代，点击年代可访问来源。中世纪用于跨风格的时期检索。建设、重建、开放和增建采用各自对应的历史阶段。

## 运行

用现代浏览器打开 dist/index.html。Three.js、模型生成代码、材质和页面样式已内嵌，无需 CDN。网页支持旋转、缩放、全屏、材质开关、剖切和构件热点。巴黎圣母院、科隆大教堂另有屋顶拆解、肋架与支撑分类视图。

## 构建与检查

在解压后的项目文件夹内运行 `node build.mjs`，输出 dist/index.html。可通过 ATLAS_EXPORT 指定额外单文件输出路径。`node tests/validate-structure.mjs` 实例化全部 100 座建筑，检查几何、法线、纹理坐标与图层。

模型、材质与应用代码使用 MIT 许可，Three.js 的 MIT 许可见 dist/vendor/LICENSE.txt。原创教学模型采用简化的构件和室内空间，无法用于尺寸测量或结构计算。

## 100 座馆藏版本

新增 50 座包括沙特尔、圣家堂、凡尔赛宫、萨伏伊别墅、朗香教堂、埃菲尔铁塔和伦敦塔桥等建筑。新增模型与资料位于 `expansion.js`，可编辑数据清单位于根目录 `collection-additions.json`。年代链接指向 UNESCO、场馆或建筑师资料；历史街区与系列遗产链接提供建筑背景。

`node tests/validate-catalog.mjs` 检查馆藏数量、分类、年代链接和单文件打包；`node tests/validate-structure.mjs` 检查全部 100 座模型。新增模型是按代表性体量与构件组织的教学示意，不等同于测绘模型。
